# Constellation short (Remotion template)

A 24-second vertical short: kinetic text over a constellation that connects outward from
"you" as the sky turns from night to dawn.

```bash
npm install
npx remotion studio                                        # live preview
npx remotion render ConstellationShort out/short.mp4      # render
```

Edit the script in `src/Constellation.tsx` (`BLOCKS`). See the `motion-shorts` skill for
timing and layout rules.
